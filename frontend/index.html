How to Install the Currency Converter Extension

Installing this browser-based **instant currency conversion tool** is simple and takes less than 30 seconds. Follow these quick instructions to set up the **converter**:

  1. Download the production build package (`instant-currency-production.zip`) from our landing page.
  2. Open your Chrome browser and type chrome://extensions/ in the search bar.
  3. Switch on the Developer mode toggle located in the top-right corner of the Extensions dashboard.
  4. Drag and drop the downloaded ZIP file directly onto the page, or click Load unpacked and select the directory where you extracted the package.
  5. Click the puzzle icon in the toolbar, pin HoverConvert, and enjoy automatic **instant** conversions on any site!
